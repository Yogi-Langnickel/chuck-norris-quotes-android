# Quote Battle Royal 1.4.0

## Highlights

- Added Ask Yogi with rotating advice and dad joke providers.
- Added one-slot prefetching so fact tabs and battle challengers feel faster.
- Added Champion Podium scoring across Chuck, Cat, Dog, and Yogi.
- Added the Victory Stamp winner feedback.
- Updated battle vote buttons to use source-aware "has spoken" copy.
- Made dark mode the default and aligned the battle palette with the approved
  visual proposal.
- Hardened dog facts with remote fallback and local emergency fallback.

## Quality

- Added and updated repository, service, domain, and ViewModel tests for Yogi,
  provider fallback, prefetching, and scoring behavior.
- Verified with `./gradlew testDebugUnitTest`, `./gradlew assembleDebug`, and
  release build validation before publishing.
